Giải Phương Trình Bậc Hai

Giải chính xác ax² + bx + c = 0 với lời giải từng bước chuẩn SGK Kết nối tri thức. Tích hợp đồ thị parabol tương tác, định lý Viète và module Tìm tham số m.

Hỗ trợ số nguyên, thập phân (dấu phẩy hoặc chấm) và phân số (ví dụ: -3/4).
Máy sẽ chuẩn hóa và yêu cầu bạn xác nhận trước khi giải.

📖 Lời Giải Từng Bước (Chuẩn SGK Kết nối tri thức)

Đồ thị hàm số y = ax² + bx + c

Kéo các thanh trượt bên dưới để quan sát tức thì đỉnh parabol, trục đối xứng và giao điểm với các trục tọa độ. (Khi a = 0, đồ thị tự động chuyển thành đường thẳng bậc nhất).

Giao Oy (0; c) Đỉnh I Nghiệm (Giao Ox)

Biện luận tham số m trong phương trình bậc hai

Nhập hệ số là số hoặc biểu thức bậc nhất theo tham số m (ví dụ: m-1, 2m, -m+3). Máy tự động xét riêng trường hợp a = 0 và biện luận hai lớp cho các yêu cầu liên quan.

Tự luyện phương trình bậc hai (4 cấp độ)

Đề bài được sinh tự động bằng phương pháp giải ngược từ nghiệm để số liệu luôn đẹp và chính xác.

Cách Giải Phương Trình Bậc Hai Bằng Tay Chuẩn SGK

Phương trình bậc hai một ẩn có dạng tổng quát ax² + bx + c = 0 (a ≠ 0). Dưới đây là phương pháp giải chuẩn mực trong chương trình Toán 9 (bộ sách Kết nối tri thức).

Biệt thức: Δ = b² − 4ac  (hoặc Δ' = b'² − ac khi b chẵn, b = 2b')
Δ < 0

Phương trình vô nghiệm (trên tập số thực ℝ).

Δ = 0

Nghiệm kép: x₁ = x₂ = −b / (2a)

Δ > 0

2 nghiệm phân biệt: x₁,₂ = (−b ± √Δ) / (2a)

⚠️ Ba lỗi sai học sinh hay mất điểm nhất:

1 Quên đổi dấu khi chuyển vế

Khi gặp x² = 5x − 6, nhiều bạn viết nhầm thành x² − 5x − 6 = 0.

💡 Quy tắc: Chuyển sang vế trái phải đổi dấu: x² − 5x + 6 = 0.
2 Kết luận sai khi Δ < 0

Tính ra số âm dưới dấu căn vẫn cố tình lấy căn bậc hai dẫn đến sai toàn bộ lời giải.

💡 Quy tắc: Khi Δ < 0, dừng lại và kết luận ngay: phương trình vô nghiệm.
3 Nhầm dấu mẫu số khi a âm

Ví dụ −x² + 3x − 2 = 0 có mẫu số là 2a = −2, rất dễ quên đổi dấu ở tử số.

💡 Quy tắc: Nhân hai vế với −1 để đưa về x² − 3x + 2 = 0 trước khi tính Δ.

Năm Ví Dụ Giải Mẫu Chuẩn Quy Cách SGK

Ví dụ 1

Hai nghiệm nguyên phân biệt

x² − 5x + 6 = 0

Ta có: a = 1, b = -5, c = 6.
Δ = (-5)² − 4 · 1 · 6 = 1 > 0.
Nghiệm: x₁ = (5 + 1)/2 = 3; x₂ = (5 − 1)/2 = 2.
Dạng nhân tử: (x − 2)(x − 3) = 0. Tập nghiệm S = {2; 3}.
Ví dụ 2

Phương trình có nghiệm kép

x² − 4x + 4 = 0

Ta có: a = 1, b = -4, c = 4.
Δ = (-4)² − 4 · 1 · 4 = 0.
Vì Δ = 0 nên phương trình có nghiệm kép: x₁ = x₂ = −(-4)/(2 · 1) = 2.
Ví dụ 3

Phương trình vô nghiệm

x² + 2x + 5 = 0

Ta có: a = 1, b = 2, c = 5.
Δ = 2² − 4 · 1 · 5 = -16 < 0.
Vì Δ < 0 nên phương trình vô nghiệm trên tập số thực ℝ.
Ví dụ 4

Hệ số a khác 1 và nghiệm phân số

2x² + 3x − 2 = 0

Ta có: a = 2, b = 3, c = -2.
Δ = 3² − 4 · 2 · (-2) = 25 > 0 ⇒ √Δ = 5.
Nghiệm: x₁ = 0,5; x₂ = -2.
Dạng nhân tử: 2(x − 0,5)(x + 2) = (2x − 1)(x + 2) = 0.
Ví dụ 5

Delta không chính phương

x² − 2x − 1 = 0

Ta có: a = 1, b = -2, c = -1.
Δ = (-2)² − 4 · 1 · (-1) = 8 > 0 ⇒ √Δ = 2√2.
Nghiệm: x₁,₂ = 1 ± √2 (xấp xỉ 2,4142 và -0,4142).

Câu Hỏi Thường Gặp (FAQ)

❓ Biệt thức Δ (Delta) là gì và có ý nghĩa như thế nào trong giải toán?
Biệt thức Δ = b² − 4ac là một đại lượng đặc trưng được lập từ các hệ số của phương trình bậc hai ax² + bx + c = 0 (a ≠ 0). Giá trị và dấu của Δ quyết định số nghiệm thực của phương trình: nếu Δ > 0 phương trình có 2 nghiệm phân biệt; nếu Δ = 0 phương trình có nghiệm kép; nếu Δ < 0 phương trình vô nghiệm trên tập số thực ℝ.
❓ Khi nào một phương trình bậc hai bị kết luận là vô nghiệm?
Trong chương trình toán THCS và THPT (xét trên tập số thực ℝ), phương trình bậc hai ax² + bx + c = 0 vô nghiệm khi và chỉ khi biệt thức Δ = b² − 4ac < 0. Vì không tồn tại căn bậc hai số thực của một số âm, nên không có giá trị x thực nào thỏa mãn đẳng thức.
❓ Nếu hệ số a = 0 thì phương trình được xử lý như thế nào?
Khi a = 0, số hạng chứa x² triệt tiêu, phương trình suy biến thành phương trình bậc nhất bx + c = 0. Nếu b ≠ 0, phương trình có nghiệm duy nhất x = −c/b. Nếu b = 0 và c = 0, phương trình nghiệm đúng với mọi x (vô số nghiệm). Nếu b = 0 và c ≠ 0, phương trình vô nghiệm. Công cụ tự động chuyển hướng và giải thích rõ bước hạ bậc này.
❓ Khái niệm "nghiệm kép" khác gì với "hai nghiệm bằng nhau"?
Về mặt bản chất toán học, "nghiệm kép" chính là trường hợp hai nghiệm phân tích x₁ và x₂ trùng một giá trị số: x₁ = x₂ = −b/(2a). Trong SGK lớp 9 (Kết nối tri thức), khi Δ = 0 sách dùng thuật ngữ "phương trình có nghiệm kép" để nhấn mạnh đa thức bậc hai ax² + bx + c được viết thành bình phương của một nhị thức bậc nhất a(x − x₀)².
